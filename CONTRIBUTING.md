# Rules

Thanks for helping make this list better. To keep it useful, every entry and pull request must follow these rules.

## What belongs here

- **Gaming only.** The list is about gaming: games, launchers, save managers, emulators, operating systems, tools and resources, or anything about GAMING. Unrelated projects do not belong.
- **Real projects.** Entries must be usable and actively maintained. Abandoned, poorly maintained, broken or vaporware projects are removed.
- **No low-effort projects.** We accept the use of AI tools, but we do not approve "weekly projects" made only to fill a slot. Or a project thats just get maintained 1 time a week-month by a AI.
- **No duplicates.** Search the list before adding something. If a better list already covers a topic, link to it instead of repeating it.

## How to add an entry

1. Add the entry to the most fitting category, or propose a new one.
2. Use the format `- [Name](https://link) ![badges] - Short description ending with a period (year).`
3. Add the licensing and pricing badges:
   - Licensing: `![Open Source][os]`, `![Proprietary][prop]`, `![Source Available][sa]` or `![Community][community]`.
   - Pricing: `![Free][free]`, `![Freemium][freemium]` or `![Paid][paid]`.
4. Write the description in your own words and say **why** it is awesome or how it helps the reader.
5. End the description with the project's first release year in parentheses, for example `(2020).`
6. Order entries within a category by first release year, oldest first. For entries that share a year, use alphabetical order.
7. Make sure links work and point to the official project page or repository.

## Quality bar

- Grammatically correct, typo-free and valid Markdown.
- Descriptions are concise (one line) and end with a period.
- No affiliate links, referral codes, tracking parameters or ads.
- Prefer open source, privacy-respecting projects with clear licensing.

## Pull requests

- One project per pull request, unless the change is a fix or a reorder.
- Explain in the description what you are adding or changing and why.
- Expect review: an entry may be declined if it does not meet the rules above. This is normal and not personal.
- Respect other people's opinions. If several contributors disagree with a decision, we will reconsider it.

## Reporting issues

Open an issue for broken links, outdated entries, or projects that no longer meet these rules. Suggest a replacement when you can.
