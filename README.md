# Awesome Gaming

> A curated list of awesome gaming things.

This is a hand-picked list of tools, launchers, save managers, operating systems, emulators and other projects that make gaming better. Every entry must follow our [rules](CONTRIBUTING.md) before it can be included.

Entries within each category are ordered by first release year. Badges show licensing (green = open source, grey = proprietary or source-available, purple = community) and pricing (blue = free, yellow = freemium, orange = paid).

## Game Launchers and Libraries

- [Steam](https://store.steampowered.com/) ![Proprietary][prop] ![Free][free] - Largest PC game platform, with library management, workshop mods and controller support (2003).
- [Lutris](https://github.com/lutris/lutris) ![Open Source][os] ![Free][free] - Open source gaming platform for Linux that helps you install, configure and run games from many stores and emulators (2009).
- [GOG Galaxy](https://www.gog.com/galaxy) ![Proprietary][prop] ![Free][free] - Launcher focused on DRM-free games, with automatic game and save updates (2015).
- [Playnite](https://github.com/JosefNemec/Playnite) ![Open Source][os] ![Free][free] - Open source video game library manager that unifies Steam, Epic, GOG, EA, Battle.net and emulators into a single interface (2017).
- [GameHub](https://github.com/tkashkin/GameHub) ![Open Source][os] ![Free][free] - Unified library for Steam, GOG, Humble Bundle and emulated games on Linux (2018).
- [Heroic Games Launcher](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher) ![Open Source][os] ![Free][free] - Open source launcher for Epic Games, GOG and Amazon Games on Linux, Windows and macOS (2021).

## Save Management and Backups

- [GameSave Manager](https://www.gamesave-manager.com/) ![Proprietary][prop] ![Free][free] - Windows tool that detects and backs up save files for a wide range of games (2009).
- [Ludusavi](https://github.com/mtkennerly/ludusavi) ![Open Source][os] ![Free][free] - Cross-platform backup tool for PC game saves, with support for 19,000+ games and a CLI for scripting (2020).
- [Hoard](https://github.com/rleeon/hoard) ![Open Source][os] ![Freemium][freemium] - Automatic, versioned game save sync across devices, with optional cloud or self-hosted storage (2026).

## Operating Systems and Distributions

- [Ubuntu](https://ubuntu.com/) ![Open Source][os] ![Free][free] - Popular, beginner-friendly Linux distribution often used as a base for gaming setups (2004).
- [Linux Mint](https://linuxmint.com/) ![Open Source][os] ![Free][free] - Comfortable, stable Linux distribution that is easy to game on (2006).
- [SteamOS](https://store.steampowered.com/steamos) ![Open Source][os] ![Free][free] - Valve's Linux-based operating system designed for gaming, powering the Steam Deck (2013).
- [ChimeraOS](https://github.com/ChimeraOS/chimeraos) ![Open Source][os] ![Free][free] - Linux distribution that turns a PC into a console-like gaming machine (2019).
- [Garuda Linux](https://garudalinux.org/) ![Open Source][os] ![Free][free] - Arch-based Linux distribution offering a gaming-focused edition (2020).
- [Nobara](https://nobaraproject.org/) ![Open Source][os] ![Free][free] - Fedora-based Linux distribution with gaming and content creation tweaks out of the box (2022).
- [Bazzite](https://github.com/ublue-os/bazzite) ![Open Source][os] ![Free][free] - Fedora-based, containerized Linux image built for gaming on desktop and handhelds (2023).

## Compatibility Layers

- [Wine](https://www.winehq.org/) ![Open Source][os] ![Free][free] - Compatibility layer that runs Windows applications on Linux, macOS and BSD (1993).
- [DXVK](https://github.com/doitsujin/dxvk) ![Open Source][os] ![Free][free] - Vulkan-based translation layer for Direct3D 9, 10 and 11 (2018).
- [Proton](https://github.com/ValveSoftware/Proton) ![Open Source][os] ![Free][free] - Compatibility tool that lets Windows games run on Linux through Steam (2018).
- [Proton GE](https://github.com/GloriousEggroll/proton-ge-custom) ![Open Source][os] ![Free][free] - Custom Proton build with extra patches and fixes for games (2019).
- [Box64](https://github.com/ptitSeb/box64) ![Open Source][os] ![Free][free] - Emulator that runs x86_64 Linux games on ARM devices like handhelds (2020).
- [VKD3D-Proton](https://github.com/HansKristian-Work/vkd3d-proton) ![Open Source][os] ![Free][free] - Direct3D 12 to Vulkan translation layer used by Proton (2020).
- [Bottles](https://github.com/bottlesdevs/Bottles) ![Open Source][os] ![Free][free] - Tool to manage Windows software and games in Wine prefixes from a friendly GUI (2021).

## Emulation

- [MAME](https://www.mamedev.org/) ![Open Source][os] ![Free][free] - Emulator for arcade and classic computer systems with a huge game database (1997).
- [ScummVM](https://www.scummvm.org/) ![Open Source][os] ![Free][free] - Recreates the engines that power classic point-and-click adventure games (2001).
- [PCSX2](https://github.com/PCSX2/pcsx2) ![Open Source][os] ![Free][free] - PlayStation 2 emulator (2002).
- [Dolphin](https://github.com/dolphin-emu/dolphin) ![Open Source][os] ![Free][free] - GameCube and Wii emulator (2003).
- [RetroArch](https://github.com/libretro/RetroArch) ![Open Source][os] ![Free][free] - Frontend for emulators, game engines and media players, with a huge core library (2010).
- [RPCS3](https://github.com/RPCS3/rpcs3) ![Open Source][os] ![Free][free] - PlayStation 3 emulator (2011).
- [PPSSPP](https://github.com/hrydgard/ppsspp) ![Open Source][os] ![Free][free] - PlayStation Portable emulator (2012).
- [Xenia](https://github.com/xenia-project/xenia) ![Open Source][os] ![Free][free] - Experimental Xbox 360 emulator (2013).
- [mGBA](https://github.com/mgba-emu/mgba) ![Open Source][os] ![Free][free] - Game Boy Advance emulator with strong accuracy features (2014).
- [Cemu](https://github.com/cemu-project/Cemu) ![Open Source][os] ![Free][free] - Wii U emulator, open source since 2022 (2015).
- [Vita3K](https://github.com/Vita3K/Vita3K) ![Open Source][os] ![Free][free] - Experimental PlayStation Vita emulator (2018).
- [DuckStation](https://github.com/stenzek/duckstation) ![Source Available][sa] ![Free][free] - Fast PlayStation 1 emulator (2019).

## Performance and Overlays

- [CoreCtrl](https://gitlab.com/corectrl/corectrl) ![Open Source][os] ![Free][free] - Tool to control CPU and GPU settings on Linux (2019).
- [vkBasalt](https://github.com/DadSchoorse/vkBasalt) ![Open Source][os] ![Free][free] - Vulkan layer for sharpening and post-processing effects in games (2019).
- [Gamescope](https://github.com/ValveSoftware/gamescope) ![Open Source][os] ![Free][free] - Micro-compositor used by SteamOS for gaming sessions (2020).
- [Goverlay](https://github.com/benjamimgois/goverlay) ![Open Source][os] ![Free][free] - Graphical interface to configure MangoHud and other Linux overlays (2020).
- [MangoHud](https://github.com/flightlessmango/MangoHud) ![Open Source][os] ![Free][free] - Vulkan and OpenGL overlay for monitoring FPS, temperatures and GPU load (2020).
- [LACT](https://github.com/ilya-zlobintsev/LACT) ![Open Source][os] ![Free][free] - Linux GPU configuration and monitoring for AMD, Intel and NVIDIA (2021).

## Controllers and Input

- [AntiMicroX](https://github.com/AntiMicroX/antimicrox) ![Open Source][os] ![Free][free] - Graphical tool to map keyboard and mouse actions to gamepad buttons (2013).
- [DS4Windows](https://github.com/Ryochan7/DS4Windows) ![Open Source][os] ![Free][free] - Aids using DualShock 4 and DualSense controllers on Windows (2014).
- [Steam Input](https://store.steampowered.com/) ![Proprietary][prop] ![Free][free] - Controller configuration built into Steam, with per-game layouts and community profiles (2015).
- [sc-controller](https://github.com/kozec/sc-controller) ![Open Source][os] ![Free][free] - Configures the Steam Controller and other gamepads on Linux desktop (2016).

## Streaming and Remote Play

- [Steam Remote Play](https://store.steampowered.com/remoteplay) ![Proprietary][prop] ![Free][free] - Stream games from one PC to another or to a mobile device (2014).
- [Parsec](https://parsec.app/) ![Proprietary][prop] ![Freemium][freemium] - Low-latency game streaming with a free tier and paid plans for higher quality (2016).
- [Moonlight](https://github.com/moonlight-stream/moonlight-qt) ![Open Source][os] ![Free][free] - Open source game streaming client for NVIDIA GameStream and Sunshine (2018).
- [Chiaki](https://github.com/thestr4ng3r/chiaki) ![Open Source][os] ![Free][free] - Open source client for PS4 and PS5 Remote Play (2019).
- [Sunshine](https://github.com/LizardByte/Sunshine) ![Open Source][os] ![Free][free] - Self-hosted game stream host compatible with Moonlight clients (2022).

## Game Development

- [Pygame](https://www.pygame.org/) ![Open Source][os] ![Free][free] - Python library for making 2D games quickly (2000).
- [Ren'Py](https://www.renpy.org/) ![Open Source][os] ![Free][free] - Engine for making visual novels and interactive fiction (2004).
- [LÖVE](https://github.com/love2d/love) ![Open Source][os] ![Free][free] - Framework for making 2D games in Lua (2008).
- [MonoGame](https://www.monogame.net/) ![Open Source][os] ![Free][free] - Cross-platform C# framework for desktop and console games (2009).
- [libGDX](https://github.com/libgdx/libgdx) ![Open Source][os] ![Free][free] - Cross-platform Java game development framework (2010).
- [Phaser](https://github.com/phaserjs/phaser) ![Open Source][os] ![Free][free] - Popular 2D game framework for browsers in JavaScript (2013).
- [raylib](https://github.com/raysan5/raylib) ![Open Source][os] ![Free][free] - Simple C library for prototyping and making games across platforms (2013).
- [Godot](https://github.com/godotengine/godot) ![Open Source][os] ![Free][free] - Free and open source game engine for 2D and 3D games (2014).
- [Bevy](https://github.com/bevyengine/bevy) ![Open Source][os] ![Free][free] - Data-driven game engine built in Rust (2020).
